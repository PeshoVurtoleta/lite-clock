scene 04 -- 1K active lanes

1000 lanes with randomized durations all running together. histogram below shows t-distribution updated every 8 frames. zero-alloc telemetry: Float64Array ring buffer, ~10Hz throttled text.

The stress harness spawns 1000 lanes with random durations [200ms, 4000ms] and recycles completed lanes each frame by polling donePeek() so the active count stays steady (callback-less completions still count in stats().totalCompletions). Switch the driver to attachFixed(4, { maxSubSteps: 4 }) to cap catch-up: excess whole quanta after a stall are dropped and counted in stats().droppedMs. Each frame: lane scan + activeList compaction + one frame signal write. Telemetry reads ONE zero-alloc stats(statsSink) fill into a module-init sink; sampling uses a Float64Array(512) ring buffer (256 paired entries, power-of-2 bitmask & 511), and text + SVG histogram updates throttle to every 8 frames via (frame & 7) === 0.

scene 05 -- snapshot / rollback
